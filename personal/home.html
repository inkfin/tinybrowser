Tinybrowser

A small, personal browser for the terminal.

Space / right click menu · : command bar · Ctrl-P find command · F1 help

Start

  • Press o or Ctrl-L for a URL or search words. Use ./file.html for a local file.
  • hjkl move · f follow link · / find text · H / L previous / next buffer.
  • Click links, use the wheel to scroll, drag to select text. Middle click opens a link in a background tab.
  • gi toggle images · gr toggle website CSS · gx open in your system browser.

For X, use :x to open your system browser. Use :external for any current web page that needs it.

Website scripts and cookies start disabled. The menu shows their state. Images need a Kitty/Sixel terminal; use gi to hide them.
