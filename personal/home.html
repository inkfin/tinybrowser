Tinybrowser

A small, personal browser for the terminal.

Space menu · : command bar · Ctrl-P find command · F1 help

Start

  • Press o to open a URL. Type s: your question to search.
  • hjkl move · f follow link · / find text · H / L previous / next buffer.
  • gi toggle images · gr toggle website CSS.
